# TIP8311 – Trabalho Computacional 3  
## Classificação Estatística e Redução de Dimensionalidade

Implementação dos classificadores gaussianos e análise do impacto da redução de dimensionalidade via PCA.

---

## 📌 Descrição

Este projeto contempla:

- Análise de invertibilidade de matrizes de covariância
- Implementação do Classificador Quadrático Gaussiano (CQG)
- Implementação do Discriminante Linear com Covariância Compartilhada (DMP)
- Redução de dimensionalidade com PCA (95% variância explicada)
- Avaliação estatística com 100 execuções independentes

Disciplina: Reconhecimento de Padrões (TIP8311)  
Programa de Pós-Graduação em Engenharia de Computação – UFC
